## 功能

### 应用双开
将应用安装进独立容器运行，同一台设备可同时登录两个账号。容器之间数据隔离，
一个应用在后台运行时不会唤醒另一个。

### 单机应用省时
对不需要联网的单机应用，可调整运行节奏，跳过重复的动画与等待环节。
**联网对战类应用不适用，本项目不支持也不鼓励此类用途。**

### 轻量
安装包 5 MB，无广告，无后台常驻，不用时不耗电。

## 安装

1. 下载 `xincheng-v2.1.2.apk`
2. 允许浏览器「安装未知来源应用」
3. 打开安装包，按提示完成安装

### 各厂商注意事项

| 厂商 | 需要做的事 |
|---|---|
| 华为 / 荣耀 | 设置 → 安全 → 纯净模式 → 关闭增强防护，否则安装被拦截 |
| 小米 / 红米 | 安装时提示「风险应用」选择「仍要安装」 |
| OPPO / vivo | 允许安装未知来源应用 |

## 已知限制

- 带反虚拟化检测的应用（部分银行、支付类）可能无法在容器内正常运行
- 不支持 32 位与 64 位应用混装在同一容器
- 部分定制系统会限制后台容器存活，需要在系统设置里加白名单

## 常见问题

**Q：装不上，提示「应用未安装」或直接被拦截？**
A：华为/荣耀先关闭纯净模式；其他机型检查是否允许未知来源安装。

**Q：双开的应用收不到消息？**
A：在系统设置里给本应用开启「自启动」和「后台运行不受限制」，部分系统还需要锁定后台。

**Q：能用于联网对战类应用吗？**
A：不能，也不建议。本工具只调整单机应用在本地运行时的节奏，不涉及网络传输，也不修改任何
在线数据。用于在线对战、竞技类应用违反其服务条款，可能导致账号被限制，后果由使用者自负。
